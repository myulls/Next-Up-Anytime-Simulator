# Next Up Anytime Upgrade Simulator

## Overview

Interactive proof-of-concept designed to improve customer understanding of smartphone financing and upgrade options.

The simulator enables customers to:

- Select an iPhone model
- Compare Next Up Anytime versus standard 36‑month installment plans
- View monthly payment differences
- Understand upgrade eligibility timing
- Compare upgrade flexibility and ownership costs

## Purpose

This prototype was developed to explore opportunities for increasing customer engagement and improving decision-making within the AT&T digital purchase experience.

- JavaScript
